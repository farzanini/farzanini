# Hi, I'm Farzan Hosseini

**AI & Software Engineer** — I build production LLM agents for finance and ERP automation, on top of eight years of full-stack and enterprise engineering.

## What I'm working on

- **AI agents for accounting back-offices** (Agentee) — LLM agents that turn emailed invoices and orders into booking drafts in Microsoft Dynamics NAV and DATEV, with an accountant in the loop. My focus is making agent behavior measurable and trustworthy: extraction evaluation harnesses, line-level provenance, deterministic ERP replay, and checks against the system of record before the agent claims anything is done.
- **An enterprise platform rewrite for air-gapped environments** — leading the ground-up rewrite of an office-automation and correspondence product (.NET, Keycloak, Linux containers), from spec and architecture to identity and CI.
- **Fintech front ends** — customer and admin apps for a bank's digital-asset tokenization platform (Next.js, TypeScript, Kubernetes, OpenTelemetry).
